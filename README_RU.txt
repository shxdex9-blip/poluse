POLUS SKINS — пакет для запуска первой обновлённой версии

СОДЕРЖИМОЕ
- bot/main.py — Telegram-бот на aiogram 3, основанный на присланном исходнике.
- webapp/ — адаптивная голубая витрина Mini App с каталогом и изображениями.
- api/app.py — API и проверка подписи Telegram initData.
- run_bot.py / run_api.py — запуск бота и API.
- .env.example — пример настроек.

БЫСТРЫЙ ЗАПУСК НА WINDOWS
1. Установите Python 3.11 или новее. При установке включите Add Python to PATH.
2. Распакуйте архив в отдельную папку.
3. Дважды нажмите install_windows.bat.
4. Откройте созданный файл .env в Блокноте и заполните:
   BOT_TOKEN — действующий токен из BotFather;
   ADMIN_ID — ваш числовой Telegram ID;
   PAYMENT_URL — платёжная ссылка.
5. Запустите start_bot_windows.bat.

MINI APP
Для локальной проверки запустите start_miniapp_windows.bat и откройте http://127.0.0.1:8000.
Чтобы Mini App открывался внутри Telegram, API и webapp нужно разместить на сервере с публичным HTTPS-доменом, затем настроить URL Web App в BotFather. Локальный запуск сам по себе не публикует приложение в интернете.

БАЗА ДАННЫХ
Бот создаёт SQLite-файл polus_skins.db в текущей рабочей папке. Если нужно сохранить данные прежнего бота, остановите старый бот, сделайте копию старой БД и перенесите её в эту папку под именем polus_skins.db. Не заменяйте единственную копию. Если структура старой БД отличается, сначала проверьте миграцию на копии.

БЕЗОПАСНОСТЬ
Не отправляйте никому .env и файл базы. Не помещайте токен в исходный код. Если токен когда-либо публиковался, отзовите его через BotFather и создайте новый.

ГРАНИЦЫ ЭТОЙ СБОРКИ
Это запускаемый пакет первой версии, а не полностью законченная реализация всех обсуждавшихся функций. Mini App содержит каталог и основу API/Telegram-аутентификации. Полные сценарии заказов через Mini App, клиентский/художнический кабинеты, рейтинги и отзывы, чаевые, чат с художником, AI-помощник «Холодок», полноценная админ-панель и генератор 2D/3D-тотемов требуют дальнейшей разработки и тестирования. Не объявляйте их готовыми к работе на основании наличия интерфейсных заготовок.
